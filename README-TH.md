# Bewpakorn Queue 1.3.0

ส่วนขยาย Chrome จัดคิวออเดอร์แมพจากเก่าไปใหม่ เปิดหน้าแก้ไขออเดอร์ ล็อกอินบัญชีลูกค้าผ่านเบราว์เซอร์แยก และนำเข้าบัญชีที่ยืนยันแล้วไป Bewpakorn RAM คุณเปิดเกม ส่งของ และเปลี่ยนสถานะบนเว็บเอง

## ใช้งาน

1. เปิด Bewpakorn RAM และปลดล็อก แล้วเข้าสู่ระบบเว็บร้านใน Chrome
2. ในหน้าตั้งค่าเลือกแมพและสินค้าที่จะทำ เช่น เลือกเฉพาะ Cameraman Tower Defense แล้วบันทึก
3. กดไอคอน Bewpakorn Queue เพื่อเริ่ม ระบบเลือกออเดอร์ PROCESSING ที่เก่าสุดจากทุกหน้า และใช้แท็บแก้ไขออเดอร์เบื้องหลังแท็บเดิม
4. ช่อง **บัญชีลูกค้า** เลือกได้ทั้งบัญชีจากออเดอร์นี้และบัญชีที่มีใน RAM ช่อง **บัญชีของคุณ** เลือกจาก RAM การเลือกมีผลเฉพาะงานนี้
5. เมื่อล็อกอินจากออเดอร์สำเร็จ ระบบตรวจตัวตนและยืนยันว่าบันทึกเข้า RAM แล้ว บัญชีที่เลือกจาก RAM จะตรวจเซสชันเดิมโดยไม่เขียนทับหรือนำเข้าซ้ำ
6. ถ้าพบรหัสผิด OTP CAPTCHA หรือปัญหาอื่น ระบบแจ้งสาเหตุแล้วรอคุณจัดการ เมื่อจะไปคิวถัดไปให้กด **สำเร็จ**
7. กด **ย้อนกลับออเดอร์** เพื่อกลับไปออเดอร์ล่าสุดที่เคยกดสำเร็จ งานที่ค้างอยู่จะกลับไปเข้าเงื่อนไขคิวเก่าสุดตามปกติ การย้อนกลับไม่เปลี่ยนสถานะในเว็บ

รุ่นนี้ไม่มีการเปิดหรือปิด Roblox อัตโนมัติ ไม่มีการตรวจห้อง Private หรือบังคับสองไคลเอนต์ คุณเลือกบัญชีและเข้าเกมใน RAM เอง

## ความหมายของสถานะ

**พร้อมใช้งานใน RAM** หมายถึงตรวจเซสชันบัญชีได้ และในกรณีบัญชีจากออเดอร์ได้ยืนยันการนำเข้าแล้ว คุณยังต้องเปิดเกมและตรวจสินค้าเอง

ออเดอร์ที่ย้อนกลับมาและเว็บเป็น COMPLETED ยังสามารถล็อกอินได้เพราะคุณสั่งย้อนกลับเอง ส่วน FAILED/CANCELLED/REFUNDED จะให้ดูข้อมูลและเลือกบัญชี RAM เอง โดยไม่อ่านรหัสเพื่อล็อกอินอัตโนมัติ

การเปลี่ยนบัญชีลูกค้าจะยกเลิกหน้าล็อกอินเดิม การเปลี่ยนบัญชีของคุณจะคงหน้าล็อกอินลูกค้า/OTP ไว้ เลือกสองช่องเป็น UserID เดียวกันไม่ได้ หาก RAM ยังไม่ยืนยันผลนำเข้า ระบบรอให้ผลเดิมชัดเจนก่อนเปลี่ยนบัญชีหรือคิว

## ติดตั้งหรืออัปเดต

รัน `scripts\install.ps1` โดย RAM ปกติอยู่ `Desktop\bew` ถ้าอยู่ที่อื่นใช้ `-RamDirectory 'โฟลเดอร์ RAM'` ไม่ต้อง Administrator

โหลดส่วนขยายจาก `%LOCALAPPDATA%\BewpakornQueue\extension` ใน `chrome://extensions` ตรวจ ID `fniggkiipecbpmobhcgkehbmjlgkldop` ถ้าเดิมโหลดจาก `D:\BewpakornQueue-1.0.0\extension` ให้ใช้ไฟล์ใหม่ในโฟลเดอร์นั้นแล้วกด **Reload** หนึ่งครั้ง

ข้อมูลคิวและประวัติเดิมเก็บไว้ ไม่มีการเริ่มออเดอร์ใหม่ตอนติดตั้งหรือเปิด Chrome หากมีงานเดิมที่ล็อกอินไม่สำเร็จ กดไอคอนเพื่อเตรียมงานเดิมอีกครั้งได้

## การเก็บข้อมูล

รหัสผ่านใช้ชั่วคราวในหน่วยความจำและหน้าล็อกอินแยก ไม่เก็บในประวัติหรือ Chrome storage บัญชีใหม่ใน RAM อยู่ Default และบัญชีเดิมคง alias/description/group เดิม ระบบจำไอดีร้านที่ป้องกันไว้แม้คุณปิดแมพนั้นในตั้งค่า
