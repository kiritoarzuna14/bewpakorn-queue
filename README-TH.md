# Bewpakorn Queue 1.1.1

ผู้ช่วยเตรียมบัญชี Roblox สองฝั่งสำหรับออเดอร์แมพ: บัญชีลูกค้า + บัญชีร้านใน Bewpakorn RAM เรียงเก่าสุดก่อน เปิดหน้าแก้ไขออเดอร์ไว้ให้ แล้วรอปุ่ม **สำเร็จ** เพื่อไปงานถัดไป

รุ่น 1.1.0 เปิด Roblox **สองไคลเอนต์พร้อมกัน** สำหรับออเดอร์เดียว (ลูกค้า 1 + บัญชีร้าน 1) เข้าห้อง Private เดียวกัน และเลือกบัญชีร้านได้หลายไอดีต่อแมพโดยสลับให้อัตโนมัติ

## มีอะไรใหม่ใน 1.1.0 – 1.1.1

- **1.1.1** หน้าแก้ไขออเดอร์ของคิวถัดไปเปิดเป็นแท็บเบื้องหลัง ไม่สลับแท็บหรือดึงโฟกัสจากแท็บที่คุณกำลังใช้อยู่
- **บัญชีร้านหลายไอดีต่อแมพ** เช่น Cameraman ใช้ BewFNTH1 → BewFNTH2 → BewFNTH3 สลับทีละออเดอร์ตามลำดับที่ตั้งไว้ เก็บที่เลือกไว้กับงานนั้น กดซ้ำ/กู้คิว/รีเฟรชไม่สลับใหม่
- **เปิดสองไคลเอนต์จริง** ลูกค้ากับบัญชีร้านเข้าเกมพร้อมกัน ตรวจว่าเป็นบัญชีถูกต้อง คนละ process และอยู่เซิร์ฟเวอร์เดียวกันจากลิงก์ Private ที่บันทึกไว้ของบัญชีต้นทาง
- **ตัวเชื่อมถือสิทธิ์ multi-client ให้เอง** (mutex `ROBLOX_singletonMutex`) เมื่อยังไม่มีใครถือ กันไม่ให้ Roblox ตัวใหม่สั่งปิดไคลเอนต์ที่เปิดอยู่ก่อน
- **ปุ่มสำเร็จปิดเฉพาะสองไคลเอนต์ของงานนั้น** ไม่แตะเกมที่คุณเปิดเอง ถ้าปิดไม่ครบจะค้างเป็นงานรอตรวจไม่ข้ามคิว

## สิ่งที่เครื่องต้องมี

1. Bewpakorn RAM หนึ่งชุด ปลดล็อกแล้ว (ระบบหยุดถ้าพบ RAM หลายชุด)
2. WebView2 Runtime (มีใน Windows 10/11 อยู่แล้ว)
3. **เปิด RAM ขณะไม่มี Roblox เปิดค้าง** ถ้าเปิด RAM ตอนมี Roblox ค้าง RAM จะถือสิทธิ์ multi-client ไม่สำเร็จ (ตัวเชื่อมจะถือให้แทน แต่เปิดใหม่ตอนว่างจะเสถียรที่สุด)
4. Roblox Account Manager ชุดอื่นต้องปิด ให้เหลือชุด `Desktop\bew` ชุดเดียว

## ติดตั้งครั้งแรก / อัปเดต

1. เปิด Bewpakorn RAM ตามข้อกำหนดข้างบน แล้วปลดล็อก
2. รัน `scripts\install.ps1` (ไม่ต้อง Administrator) ถ้า RAM อยู่ที่อื่นใช้ `-RamDirectory 'ที่อยู่โฟลเดอร์ bew'`
3. เปิด `chrome://extensions` เปิด Developer mode แล้ว Load unpacked ที่ `%LOCALAPPDATA%\BewpakornQueue\extension` ตรวจชื่อ **Bewpakorn Queue** และ ID `fniggkiipecbpmobhcgkehbmjlgkldop`
   - ถ้าเดิมโหลดจากโฟลเดอร์อื่น (เช่น `D:\BewpakornQueue-1.0.0\extension`) ให้วางไฟล์รุ่นใหม่ในโฟลเดอร์ที่ Chrome โหลดจริงด้วย แล้วกด **Reload** ครั้งเดียว
4. เปิด Extension options เลือกแมพที่จะทำ เลือกบัญชีร้าน **ได้หลายไอดี** ตามลำดับ จากนั้นกดบันทึก
5. ล็อกอินเว็บร้านใน Chrome แล้วกดไอคอน **Bewpakorn Queue** เพื่อเริ่มงาน

ตั้งค่าและประวัติเดิมยังอยู่หลังอัปเดต ไม่เริ่มงานเองตอนติดตั้งหรือเปิด Chrome

## ใช้งานประจำ

- อ่านออเดอร์แมพที่อนุญาตและมีสถานะ PROCESSING ไล่ครบทุกหน้า เลือกเก่าสุดก่อน
- เปิดหน้าแก้ไขออเดอร์ใหม่ **เป็นแท็บเบื้องหลัง** ไม่สลับแท็บหรือดึงโฟกัสจากแท็บที่คุณใช้อยู่ และไม่รีเฟรชหน้าแก้ไขที่คุณกำลังทำ
- หน้าล็อกอินลูกค้าแยกจาก Chrome ส่วนตัว เมื่อได้เซสชันจะตรวจ UserID และนำเข้า RAM จากนั้นบัญชีร้านตรวจเซสชันที่เก็บไว้
- เมื่อทั้งสองฝั่งพร้อม ระบบเปิด Roblox สองไคลเอนต์เข้าห้อง Private เดียวกัน แล้วแจ้งสถานะ
- ถ้าติดยืนยันมือถือ/OTP/CAPTCHA/รหัสไม่ผ่าน หรือเข้าเกมไม่สำเร็จ จะแจ้งแล้วรอคุณจัดการ
- กด **สำเร็จ** เมื่อจัดการหรือผ่านงานนี้แล้ว ระบบปิดสองเกมของงานนั้นแล้วไปคิวถัดไป ไม่เปลี่ยนสถานะร้าน

## ขอบเขตและข้อจำกัด 1.1.1

- ยังไม่ตรวจ **ภาพเกมที่เรนเดอร์** อัตโนมัติ (`renderedGameplayVerified=false`) ระบบยืนยันจาก log ของเกมว่าเข้าห้องและเซิร์ฟเวอร์เดียวกัน ต้องดูหน้าจอเองว่าเข้าถึงตัวเกมจริง
- ทดสอบจริงด้วยบัญชีร้าน 2 ไอดี (BewFNTH1 + BewFNTH2) ผ่าน 2 รอบติดกัน ไอดีที่สามผ่านการทดสอบจำลอง (สลับ 1→2→3→1)
- ถ้าไคลเอนต์ใดปิดเองหรือเข้าเกมไม่ทันเวลาที่กำหนด งานจะถูกบล็อกและแจ้งรหัส ไม่ข้ามคิวและไม่ยิงซ้ำอัตโนมัติ
- “พร้อม” หมายถึงตรวจตัวตน/เซสชันตรงบัญชีและนำเข้าลูกค้า RAM สำเร็จ ไม่ใช่หลักฐานว่าส่งสินค้าแล้ว
- RAM v30 ไม่มี API ตั้งกลุ่ม บัญชีลูกค้าใหม่จึงอยู่ Default บัญชีเดิมคง alias/description/group เดิม
- ปุ่มสำเร็จไม่ลบบัญชีที่นำเข้า RAM และไม่เก็บรหัสผ่านลูกค้าเพิ่ม
- ถ้าโฮสต์หลุดกลางงาน ระบบคืนงานเดิมและแจ้งให้ตรวจสอบก่อน ไม่ลองล็อกอินซ้ำเอง

## ตรวจระบบ / ถอนติดตั้ง

`scripts\verify-installed.cjs` ตรวจ handshake, WebView2 และจำนวนบัญชีที่อ่าน metadata ได้ ไม่เริ่มออเดอร์หรือนำเข้าเซสชัน

ถอนส่วนขยายจาก Chrome แล้วรัน `scripts\uninstall.ps1` เก็บประวัติคิวและบัญชี RAM ไว้

ซอร์สและชุดทดสอบมาด้วย: `node --test tests/*.test.mjs tests/extension/*.test.mjs` (31 กรณี) และ `scripts\build-native.ps1` ที่รัน self-test ของ native รวมชุดทดสอบ dual-client แบบจำลอง
